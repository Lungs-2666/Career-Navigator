# Career Navigator
A fullstack application for programmers and designers to improve their skills.


## Get Started:

1. Clone this repository
```bash
git clone ''
```

2. Install dependencies
```bash
npm install
```

3. Create .env.local as the .env.example and fill the keys/links

4. Initialise the project
```bash
npm run dev
```
## Main Stack:

- NextJS
- CSS3
- MongoDB
- PostgreSQL
- Supabase
- ReactFlow
- ReactBits
